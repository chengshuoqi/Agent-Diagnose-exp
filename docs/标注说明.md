# 输出结果与标注状态说明

## 当前 `output/annotations.csv` 的来源

**这批分数是 AI 模拟的，不是真人标注。** 由 AI 按 `打分指南.md` 的 rubric 阅读 `annotations.md` 后填入，用于把管线（采集 → 判分 → 标注 → 相关性）先跑通。

因此 `output/correlation.md` 里算出来的是 **"LLM 标注员 vs LLM judge"**，不是论文 Table 1 的"人类 vs 机器"：

- 同族模型共享偏好（偏好有条理的文字、偏好具体名词、对"结果正确"不敏感），相关性会被**系统性高估**；
- 不能当作论文 0.57 的复现结果写进报告；
- 标注时 AI 已看过部分 judge 分数，无法宣称完全独立。

## 要变成可写进报告的数据

```powershell
cd repro

# 1) 生成一份空白打分表（不动现有结果）
.\.venv\Scripts\python.exe code\make_annotation_sheet.py --out output\annotations_human.csv --md output\annotations_human.md

# 2) 复制两份，两位同学各自独立打分（不讨论），对照 annotations_human.md
copy output\annotations_human.csv output\annotations_a.csv
copy output\annotations_human.csv output\annotations_b.csv

# 3) 讨论分歧后合并成一份，重算相关性
.\.venv\Scripts\python.exe code\correlate.py --annotations output\annotations_final.csv
```

## 编辑 CSV 的注意事项

用 Excel / WPS 打开 CSV 再保存，**默认会存成 GBK/ANSI**，`correlate.py` 读取时会报 `UnicodeDecodeError`。请：

- 另存为时选「**CSV UTF-8**」，或
- 直接用文本编辑器（VS Code / 记事本）修改。

如果已经存坏了，用记事本打开另存为 UTF-8，或重新生成一份再填。
