## 验收结论

改造目标的两条都达成：

1. **错配不可能通过**——拿旧产物、篡改轨迹、篡改标注三种方式试，全部被拒（V1.1–V1.3）。
2. **「没数据」说得清**——空标注、n<3、单侧缺失都有明确措辞，不再打印一个孤零零的 `-`（V3.1/V3.4）。

**但这套改造没有让结论变好，反而让结论变诚实**：A 的 0.81 与 B 的 0.47 都是真数字，差异的原因见
[`实验报告.md`](实验报告.md) §5——**不是 rubric 不稳，是两批数据的方差结构不同**。
